## Phase 2 — MVC gaps, receipts, Option 4

`DocumentController@show`, `PhotoController@show`, `ProjectTimelineController@show`,
`ReceiptController@show`/`@edit`, `ProjectShareController@index`; parent-resource

**2.2 ReceiptProcessingService repair**: `:34` → inject `ReceiptParser`, call
`$this->parser->parse($text)`. `createExpenseFromData()` must consume `$receiptPath`
instead of ignoring it (`:43,58`). Fixes B-1c.

**2.3 Receipts writer — decision #4**

```
analyze()   → OCR → preview to browser (unchanged UX)
store()     → re-run OCR from temp_path   ← AUTHORITATIVE (memoised by content hash)
            → match/create Expense (client fields still used for editable UI fields)
            → attachReceiptMedia() → Spatie `media` row  (image bytes UNCHANGED)
            → Receipt::create() with file_path mirroring the media URL + server-derived extracted_*
storeBulk() → same per row
```

```php
// ReceiptController::attachReceiptMedia() — after ->toMediaCollection('receipt'):
$media = $expense->getFirstMedia('receipt');

Receipt::create([
    'expense_id'          => $expense->id,
    'filename'            => $media->file_name,
    'original_name'       => $media->name,
    'file_path'           => Str::after($media->getUrl(), '/storage/'),
    'file_size'           => $media->size,
    'mime_type'           => $media->mime_type,
    'ocr_data'            => $parsed,
    'ocr_confidence'      => $ocr['confidence'] ?? null,
    'extracted_text'      => $ocr['text'] ?? null,
    'extracted_amount'    => $parsed['total'] ?? null,
    'extracted_date'      => $parsed['date'] ?? null,
    'extracted_merchant'  => $parsed['merchant'] ?? null,
    'ocr_provider'        => $ocr['source'] ?? null,
    'processed_at'        => now(),
    'verification_status' => 'pending',
]);
```

## Ground rules

1. Do not modify any file until a plan for it is approved.
2. Destructive schema changes need item-by-item approval (Phase 5).
3. Prove "unused" with greps + a confidence rating (always include `node_modules`
   when third-party CSS classes are involved).
4. Preserve behaviour.
5. One commit per step, message written to `.git\COMMIT_MSG_TMP` (UTF-8, no BOM),
   committed with `git commit -F`.
6. Gate after every step: `php artisan test` · `npm run test:js` · `npm run build`.
